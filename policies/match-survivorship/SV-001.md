# SV-001 Source trust order

**Autonomy:** A – Agent decides · **Agent:** Match & merge · **Owner:** Customer master governance

## In plain English

Each attribute of the Business ready record takes the value from its most trusted source. Where sources disagree, the higher-ranked source wins and the decision is recorded with this policy.

## Conditions and actions

| Condition | Action | Decided by |
| --- | --- | --- |
| Legal name, DUNS, parent | D&B | Agent |
| Standardized address | Address validation | Agent |
| Tax ID | Validated tax document, then SAP | Agent |
| Payment terms, credit limit | SAP, then policy default | Agent |
| DEA and state license | LexisNexis, then issuing authority | Agent |

## Exceptions

A value that fails validation never wins, whatever the source rank.
