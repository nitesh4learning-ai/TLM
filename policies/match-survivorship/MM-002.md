# MM-002 Duplicate threshold

**Autonomy:** B – Agent decides, human approves above limit · **Agent:** Match & merge · **Owner:** Customer master governance

## In plain English

Compare a request with existing records. At 0.95 or above, treat it as the same customer and link it. From 0.80 to below 0.95, a data steward decides. Below 0.80, create a new customer.

## Conditions and actions

| Condition | Action | Decided by |
| --- | --- | --- |
| Match score 0.95 or above | Link to existing record; add new sales areas only | Agent |
| Match score 0.80 to below 0.95 | Hold for review with the candidates side by side | Data steward |
| Match score below 0.80 | Create a new customer; keep related records as references | Agent |

## Exceptions

Same address with a different tax ID is handled by MM-007a, not by score alone.
