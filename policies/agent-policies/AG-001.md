# AG-001 Autonomy matrix

**Autonomy:** H – Human decides · **Agent:** Orchestrator · **Owner:** Data governance

## In plain English

Every policy has one autonomy level. When no policy covers a decision, the request goes to a person. Levels: Agent decides; Agent decides and a human approves above a limit; Human decides.

## Conditions and actions

| Condition | Action | Decided by |
| --- | --- | --- |
| A – Agent decides | Agent acts and logs the decision with its policy | Agent |
| B – Agent decides, human approves above limit | Agent acts up to the limit; above it the request waits | Named approver |
| H – Human decides | Agent prepares the case; a person decides | Named approver |
| No policy found | Route to a person; log the gap for governance | Data steward |

## Exceptions

Changing a policy's level needs two approvals.
