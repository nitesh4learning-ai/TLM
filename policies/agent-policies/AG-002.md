# AG-002 Confidence thresholds

**Autonomy:** B – Agent decides, human approves above limit · **Agent:** Orchestrator · **Owner:** Data governance

## In plain English

Each agent scores its output from 0 to 1. Scores at or above the auto line proceed; scores in the review band go to a person; scores below it are rejected or sent back.

## Conditions and actions

| Condition | Action | Decided by |
| --- | --- | --- |
| Intake field confidence | Auto at 0.95+; requester confirms 0.75–0.95; steward below 0.75 | Agent / requester / steward |
| Match score | Auto at 0.95+; steward 0.80–0.95; new record below 0.80 | Agent / steward |
| D&B confidence code | Accept 8+; steward 5–7; no match below 5 | Agent / steward |
| Exclusion-list name match | Clear below 0.80; steward 0.80–0.95; block at 0.95+ | Agent / steward |

## Exceptions

A stage that fails twice stops for a person.
