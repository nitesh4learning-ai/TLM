# BPO-001 Supplier onboarding information

**Autonomy:** B – Agent decides, human approves above limit · **Agent:** Procurement · **Owner:** Procurement operations

## In plain English

For each supplier type, the BPO collects a fixed set of information before the request is accepted. The Procurement agent checks completeness and sends the BPO a list of what is missing.

## Conditions and actions

| Condition | Action | Decided by |
| --- | --- | --- |
| All suppliers | Legal name, tax ID (W-9 or W-8), address, contact, bank details with voided check or bank letter | BPO |
| Drug and device suppliers | Plus FDA establishment registration or state wholesale license | BPO |
| Services above $100,000 a year | Plus insurance certificate and signed code of conduct | BPO |
| Non-US suppliers | Plus W-8, local registration and sanctions screening evidence | BPO |
| Information complete | Move to validation | Agent |
| Information missing after two requests | Escalate to category manager | Category manager |

## Exceptions

Sole-source suppliers go to a category manager before onboarding.
